Encryption

API keys are encrypted with Fernet (AES-128-CBC + HMAC-SHA256) using the SETTINGS_SECRET_KEY environment variable before being written to PostgreSQL. Keys stored via .env are read directly from the environment and never persisted to the database.

Generate a key: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
